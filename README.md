# 庭園の写ろい — Transient Teien Colors

日本庭園の色彩と陰翳をiPadで愛でる、高輝度・多色抽象アートアプリ。
外部依存ライブラリなしの **シングルファイル Web アプリ**（`index.html`）です。

## 使い方

`index.html` をブラウザで開くだけで動作します。ビルド不要・サーバー不要。
iPad などのタブレットを縦置き/横置きにして、インテリアクロックのように飾る用途を想定しています。

- **季節** … 春 / 夏 / 秋 / 冬 を切り替え（色彩は破棄されず滑らかに写ろいます）
- **天候** … 晴 / 雨 / 曇 / 雪 の計 **16 パターン**
- **タップ** … 画面をタップすると水紋が広がります
- **設定パネル** … グリップをタップすると完全に格納。下端の淡いタブで復帰します
- **ダブルタップ** … 対応端末でフルスクリーン

## 実装のポイント

| 手法 | 目的 |
| :--- | :--- |
| **低解像度Canvas × バイリニア補間** (`RENDER_SCALE = 0.5`) | 内部を半解像度で描画しCSSで拡大。境界線を消し「濡れ和紙のにじみ」を最軽量で実現 |
| **多色パッチ・システム** (`ColorDroplet` × 60) | 画面の10〜15%径の真円を浮遊させ、灰色に濁らせず豊かな多色テクスチャを維持 |
| **境界なきお庭の島** (`GardenCircle` × 12) | 呼吸するように伸縮する中景の色の島。奥行き（陰翳）を付与 |
| **半透明ベースの塗り重ね** | 濡れた紙に絵の具がじわーっと溶ける持続的なにじみ |

## 天候演出

- **晴** … 木漏れ日のきらめき粒子（`lighter` 合成）が浮遊しては溶けて消える
- **雨** … 彩度（不透明度）1.2倍。絶え間ない雨紋（さざなみ）が自動で広がる
- **曇** … 乳白色ベース、にじみ 1.2 倍。水墨画・霧絵のような幽玄さ
- **雪** … 白い光の枠（ヴィネット）と、フチをぼかした雪の粒子が降り積もる

## カラーデータベース

四季それぞれのパレットは、実景の日本庭園写真から抽出し、濁りを取り除いて
高彩度・高明度化した「絵の具としての純色」を `teienColorDatabase`（`index.html` 内）に定義しています。
